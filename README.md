The major objectives of this internship were:

- Build backend applications using **Spring and Spring Boot**.
- Develop and consume **RESTful APIs**.

- Learn professional development tools such as **Git, GitHub, Maven and Postman**.
- Understand the complete workflow of developing a full-stack application.
